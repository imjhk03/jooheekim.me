I'm still using the Codex Plus plan, so sometimes I need to use a lot of tokens before my usage resets.

For me, working on a new feature could be great, but after working on one, I need to review the code. Bypassing that and assuming "It will work" doesn't feel right for me. So I needed to find another way to use it.

I've found that running tests, creating test data, and taking before-and-after screenshots work for me. These kinds of tasks can be tedious, but the AI agent can create test data using a computer or a similar tool to run a device simulator. Or, if I want to know whether the changes are working, I can tell it to take screenshots before and after. These screenshots can later be useful when writing future PRs.

I know I may be slow in this fast-moving AI space, but things are slowly starting to "click" for me as I figure out how to use AI in a way that works for me.

So, yeah, do testing if you need to use a lot of tokens. There are great test prompts; use them or ask the AI to create test data or screenshots.
