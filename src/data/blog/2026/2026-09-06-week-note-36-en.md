Aug 31–Sep 6, 2026

It rained for several days, and I was too busy with the app release to go running. It felt good to work up a sweat again after such a long time. I was reminded once more that exercise is the most effective of the many things that keep me going. I’ve been rushing around lately because of everything I need to do, so I promised myself that I would at least exercise enough to get through each day.

I’ve been using the GPT-5.6 Luna Max model to use my tokens efficiently, but the results have been getting subtly worse. I have to specify things that it used to handle well, and it often leaves things out. Even when I create a spec document and ask it to work from that document so the process will be more thorough, there are still things it misses. Sol or the recently released Astra model might produce better results, but I’m still being cautious because I’m worried my token usage might increase too much on the Plus plan. I’m adjusting my workflow so I can test one specific task and check how many tokens it uses.

I’m busy making images for the app’s marketing and immediately preparing the next version. I need to account for my hospital stay, surgery, and recovery afterward, so I’m preparing in advance because I won’t be able to work properly during that time. I keep wondering whether I should push myself a little, but I also think, if not now, when will I ever be this busy again? I don’t know whether I should finish at least all the necessary work before I go, or do only what I can without overexerting myself.

Still, let’s get through September while checking that I’m not sick, sleeping well, and eating properly. Something good has happened, so let’s hold on to hope.
